# Spotify Now Playing Widget

A simple widget for the [Übersicht](http://tracesof.net/uebersicht/) app that shows the currently playing track on Spotify.

## Features
- Displays the song title, artist, and album.
- Shows album artwork.
- Play, pause, and skip buttons.

## Setup
1. Install [Übersicht](http://tracesof.net/uebersicht/).
2. Clone this repository into your Übersicht widgets folder:
   ```
   git clone https://github.com/your-username/spotify-now-playing-widget.git
   ```
3. Launch Übersicht, and the widget should appear.
4. Make sure Spotify is running for the widget to display the currently playing track.
